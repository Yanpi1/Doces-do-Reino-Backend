Sobre o Projeto

Este projeto foi criado pela Igreja do Reino com o objetivo de arrecadar um determinado valor para um propósito maior. Encontramos neste formato uma maneira prática e acessível de mobilizar pessoas e tornar possível a realização desse objetivo.

A iniciativa une organização, dedicação e colaboração, permitindo que cada contribuição faça parte de algo significativo. Mais do que um sistema de encomendas, este projeto representa um esforço coletivo em prol de uma causa maior.
